Interactive Demos

Browsers can't run C or Python directly, so these demos run JavaScript ports of the same algorithms from my code projects above.

Autocomplete

Type a prefix. Matches are found with two binary searches over the sorted list, then ranked by weight (highest first).

    Matching is case-sensitive, like the C version. The sample list is cities with rounded, illustrative population weights.

    File format: an optional first line with the count, then one weight<TAB>term per line.

    Gomoku

    Get five in a row. You are White (light stones). The computer is Black and moves first. It scores every empty square using open and semi-open sequence counts and plays the best one.

    Show the AI's sequence analysis

    Open = both ends empty. Semi-open = exactly one end empty. These counts feed the scoring function.

    Seam Carving

    Drag the slider to remove the lowest-energy vertical seams. Watch the sky and ground shrink first while detailed objects stay intact.

    Large images are scaled down to fit the demo. The result is drawn at the same scale as the original so you can see it get narrower.

    Semantic Similarity

    Words that appear in similar company are probably similar in meaning. Pick a word and some candidates, and the one with the highest cosine similarity wins.

      Run a synonym test

      One question per line: word correct-answer choice1 choice2 ... (the correct answer must be among the choices).

      Tip: the built-in text is tiny. Add a few chapters of a public-domain book (for example from Project Gutenberg) to see better results.
